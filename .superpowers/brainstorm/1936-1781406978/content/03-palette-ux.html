🔍 节点面板：搜索驱动 vs 分类浏览

A: 搜索驱动（Unity VS 风格）
🔍 搜索节点...
🔀 Branch Flow
➕ Add Data
✅ 输入 "if" → 出现 Branch
✅ 输入 "+" → 出现 Add
✅ 右键画布 → 弹出搜索框 → 输入 → Enter 创建
✅ 不用鼠标翻分类，熟练后极快
B: 分类浏览（Unreal Blueprint 风格）
▸ 🔀 Flow Control
Branch, Sequence, For Each
▸ ⚡ Events
On Press, On Change, On Mount
▸ ⚙️ Actions
▸ 📊 Data
▸ 📦 Code Blocks
✅ 新手友好，能看到所有选项
❌ 节点多了以后翻找很慢
❌ 占用侧边栏空间

🏗️ 现有面板如何改造？

🗑️ 移除/合并
• BlockPalette → 被 NodePalette 替代
• StatePanel → 被 VariablePanel 替代
• CodeEditorPopup → 仅 Code Block 节点保留
✨ 新增
• NodePalette — 搜索+分类节点面板
• VariablePanel — 可视化变量管理
• NodeConfigPanel — 点击节点显示配置
✅ 保留
• FunctionLibrary — fn 定义仍需文字
• ComponentPalette — 设计模式保留
• PropertyPanel — 检查器保留

📐 数据模型变更

ElementData 增加 nodeCategory + 端口元数据
// 当前 ElementData
{
  id, nodeType: "view"|"codeblock"|"group", tag, props,
  children, parentId, ports, source, ...
}

// 新增字段:
{
  nodeCategory: "flow"|"event"|"action"|"data"|"variable"|"code",
  ports: [
    { name, direction: "in"|"out",
      portType: "flow"|"data",  // ← 新：区分流类型
      dataType: "i32"|"bool"|"any"|"void",
      configurable: true|false,      // ← 新：是否可配置
      defaultValue: ...              // ← 新：默认值
    }
  ],
  config: {                           // ← 新：节点配置
    operator: "+"|"-"|"=="|">"|...,  // Math/Compare 节点的操作符
    comparisonType: "=="|"!="|">"|...,
    literalValue: "10",              // 字面量
  }
}

🤔 问题：右键菜单 vs 搜索面板

添加节点的主要方式应该是什么？

A

右键画布 → 弹出搜索（推荐）

右键空白处 → 搜索框出现 → 输入关键词 → 下拉列表过滤 → Enter 或点击创建。类似 Unity VS / UE Blueprint。右手鼠标左手键盘，流暢高效。

B

侧边栏面板 + 拖拽

保留 ActivityBar 侧边栏，NodePalette 作为面板，节点可拖拽到画布。搜索在面板顶部过滤。适合不熟悉节点名称的新手。

C

两者都有

侧边栏保留分类浏览 + 拖拽，同时右键画布弹出快速搜索。两种方式共存，各取所需。
