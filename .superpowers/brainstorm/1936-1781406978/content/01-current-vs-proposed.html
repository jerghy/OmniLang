🤔 First Design Decision: Execution Model

Unity Visual Scripting separates Flow (execution order) from Data (values). Should we?

A

Flow + Data 分离（类似 Unity VS）

白色箭头 = 执行流（sequence），彩色线 = 数据流。Button.onPress → Branch → Set Variable 是执行流，count + 1 的结果是数据流。每个节点同时有 flow 输入/输出端口和数据端口。

B

统一连线（简化版）

不分执行流和数据流，所有连线统一处理。事件触发节点 → 自动按拓扑顺序执行后续节点。更简单但表达能力弱一些。
