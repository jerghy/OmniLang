超越 GSAP：语言级动画语法

GSAP 的灵活性 + 语言原生表达能力 = 用代码写动画，不是用配置写动画

1. 核心：to / from / fromTo 三个方向

// to —— 告诉它"去到哪里"，自动从当前值插值
motion fadeIn  = to   { opacity: 1; y: 0 }   over 300ms ease easeOut

// from —— 告诉它"从哪里来"，自动回到当前值
motion reveal  = from { opacity: 0; y: 20 }  over 400ms ease easeOut

// from → to —— 显式两端
motion morph   = from { scale: 0.8; opacity: 0 }
                 to   { scale: 1;   opacity: 1 }
                 over 500ms ease spring(200, 15)

GSAP 有 gsap.to() / gsap.from() / gsap.fromTo() —— 我们把它直接变成语言的语义，to 最常用所以最简洁。

2. 时间线：>> 链式编排（不是 method chain，是数据流）

motion entrance =
  to { opacity: 1; y: 0 }   over 300ms ease easeOut
  >> to { scale: 1.05 }     over 150ms                  // 上一段结束后执行
  >> to { scale: 1 }        over 200ms ease spring(300, 20)

// 并行用 ||
motion combo =
  to { opacity: 1 } over 300ms
  || to { x: 100 }  over 500ms

// 重叠控制（GSAP 的 "-=0.1"）
motion overlap =
  to { opacity: 1 } over 300ms
  >> to { scale: 1.1 } over 200ms @ -0.1              // 提前 0.1s 开始

// 内联时间线

> to { y: 0 } over 300ms ease easeOut
}>

3. Stagger：修饰符，不是独立类型

// stagger 可以包裹任何 motion
motion listIn = stagger(
  to { opacity: 1; y: 0 } over 300ms ease easeOut,
  each: 60ms
)

motion complexList = stagger(
  from { opacity: 0; scale: 0.8 } to { opacity: 1; scale: 1 } over 400ms,
  each: 80ms,
  from: center          // 从中间向两边扩散
)

// 直接用在元素上
<ul enter=stagger(to {opacity:1; y:0} over 300ms, each: 50ms, from: end)>

4. 触发挂载：属性即意图

<!-- 生命周期 -->
<div enter=fadeIn leave=fadeOut>

<!-- 交互 -->
<button hover=scale(1.05) press=scale(0.95)>

<!-- 信号绑定：信号值变化自动带动画过渡 -->
<div bind:style=cardMotion signal=activeCard>

<!-- 滚动驱动 -->
<section scroll=fadeIn on="top 80%">

<!-- 手势 -->
<Card drag:horizontal=swipeCard threshold=30%>

<!-- 组合触发 -->
<div enter=fadeIn hover=glow leave=fadeOut>

5. 快捷语法：常见场景一行搞定

// 无需先定义 motion，直接在元素上写！
<div enter="to {opacity:1} over 0.3s">                    // 最简单
<div enter="from {opacity:0; y:20} over 0.4s ease easeOut">
<ul  enter="stagger(from {y:20; opacity:0} over 0.3s, each:60ms)">

// 循环
<Spinner animate="to {rotate:360deg} over 1s loop infinite">

// 状态映射（类似 Vue Transition）
<div states={
  idle:    { scale: 1; opacity: 1 },
  hover:   { scale: 1.05 },
  pressed: { scale: 0.95 }
} over 150ms>

6. 物理 / 弹簧 / 缓动 —— 统一在 easing 位置

// 标准缓动（编译到 CSS easing / Flutter Curve）
ease easeOut          // 预设名
ease cubic(0.16, 1, 0.3, 1) // 自定义贝塞尔

// 物理弹簧（编译到 WAAPI 无此能力 → 用 JS 模拟；Flutter → SpringSimulation）
ease spring(200, 15)  // tension, friction
ease spring(200, 15, velocity: 2)  // 初始速度

// 弹性
ease elastic(1, 0.5)  // amplitude, period

// 回弹
ease bounce

7. 完整示例对比

GSAP（JS）
const tl = gsap.timeline()
tl.from('.card', {
  opacity: 0,
  y: 30,
  duration: 0.4,
  ease: 'power2.out'
})
tl.from('.title', {
  opacity: 0,
  x: -20,
  duration: 0.3
}, '-=0.2')
tl.from('.items li', {
  opacity: 0,
  y: 10,
  duration: 0.3,
  stagger: 0.06,
  ease: 'back.out(1.7)'
}, '-=0.1')
OmniView Motion（原生语法）
motion cardEnter =
  from { opacity: 0; y: 30 } over 400ms ease easeOut
  >> from { opacity: 0; x: -20 } over 300ms @ -0.2
  >> stagger(
        from { opacity: 0; y: 10 } over 300ms ease back(1.7),
        each: 60ms
      ) @ -0.1

<div class="card" enter=cardEnter>
  <h1 class="title">...</h1>
  <ul class="items"><li>...</li></ul>
</div>
