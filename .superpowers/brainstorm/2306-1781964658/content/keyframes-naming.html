Motion 块内部：用什么替代 keyframes？

同一个 motion-first 模型，4 种帧定义写法

A

无关键字 — 直接写百分比

motion fadeIn {
  0%   { opacity: 0; y: 20px }
  100% { opacity: 1; y: 0 }
  over: 0.3s using: easeOut
}

最干净。像 Rust match 分支一样直观。百分比本身就是帧标记。

B

poses — "姿态"

motion fadeIn {
  poses {
    0%   { opacity: 0; y: 20px }
    100% { opacity: 1; y: 0 }
  }
  over: 0.3s using: easeOut
}

动画即姿态变化。朗朗上口。可与 from/to 共存。

C

stops — "站点"

motion fadeIn {
  stops {
    0%   { opacity: 0; y: 20px }
    100% { opacity: 1; y: 0 }
  }
  over: 0.3s using: easeOut
}

旅程隐喻。motion 是旅程，stops 是沿途站台。

D

from → to 简写（无关键帧场景）

motion fadeIn {
  from { opacity: 0; y: 20px }
  to   { opacity: 1; y: 0 }
  over: 0.3s using: easeOut
}

motion bounce {
  from { y: 0 }
  40%  { y: -30px }
  60%  { y: -15px }
  to   { y: 0 }
  over: 0.6s using: easeOut
}

from/to 可混用百分比。最灵活的方案。

注意：A 和 D 都是无关键字的方案，区别在于是否用 from/to 语法糖。
