Motion 块完整结构 & 触发挂载

一个 motion 定义了"怎么动"，触发方式定义了"什么时候动"

Motion 块结构
motion fadeIn {
  // ── 帧定义 ──
  from { opacity: 0; y: 20px; scale: 0.95 }
  to   { opacity: 1; y: 0;   scale: 1 }

  // ── 时序 ──
  duration: 300ms
  delay: 0ms
  easing: easeOut              // 预设曲线
  // 或 easing: cubicBezier(0.16, 1, 0.3, 1)

  // ── 物理弹簧（替代 easing） ──
  // spring: tension(200) friction(15)

  // ── 播放 ──
  direction: normal            // normal | reverse | alternate | alternateReverse
  iterations: 1                // number | infinite
  fill: both                   // none | forwards | backwards | both
}

motion bounce {
  0%   { y: 0 }
  40%  { y: -30px }
  60%  { y: -15px }
  80%  { y: -4px }
  100% { y: 0 }
  duration: 600ms
  easing: easeOut
}
A

@motion: 统一前缀

<div
  @motion:enter="fadeIn"
  @motion:leave="fadeOut"
  @motion:hover="scaleUp"
  @motion:press="squish"
  @motion:drag="swipeCard"
  @motion:stagger="slideIn 60ms">

与现有 @onPress、@if 一致。命名空间清晰。

B

@: 简短前缀（特殊触发词）

<div
  @enter="fadeIn"
  @leave="fadeOut"
  @hover="scaleUp"
  @press="squish"
  @drag="swipeCard"
  @stagger="slideIn 60ms">

更简洁。但与 @if/@for 指令混在同一命名空间。

C

单一 motion 属性 + 子项

<div motion="{
  enter: fadeIn,
  leave: fadeOut,
  hover: scaleUp
}">

所有动画集中一处。但复杂场景括号地狱。

触发类型分类
类别 触发词 说明
生命周期 enter leave 元素挂载/卸载时
交互 hover press focus 用户交互状态
手势 drag scroll 跟手/滚轮驱动
信号绑定 bind 信号值变化时自动过渡
编排 stagger 子元素依次播放
