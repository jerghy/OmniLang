Parser-Friendly 重设计

从编译器的角度：每个 token 的语义在第一个字符就确定

1. Motion 定义块 — 清晰的边界

// @motion 关键字 → 编译器立即知道这是动画定义
@motion fadeIn {
  to { opacity: 1; y: 0 }
  over 300ms
  ease easeOut
}

@motion listItem {
  from { opacity: 0; y: 20 }
  to   { opacity: 1; y: 0 }
  over 400ms
  ease back(1.7)
}

2. then / with — 替代 >> 和 ||，无歧义关键字

@motion cardEnter {
  from { opacity: 0; y: 30 } over 400ms ease easeOut
  then to { scale: 1.05 }    over 150ms
  then to { scale: 1 }       over 200ms ease spring(200, 20)
}

// 重叠控制：at 关键字 + 有符号时间
@motion overlap {
  from { opacity: 0 }        over 300ms
  then to { scale: 1.1 }    over 200ms at -0.1s    // 提前 0.1s
  then to { x: 10 }         over 150ms at +0.2s    // 延迟 0.2s
}

// 并行：with 关键字
@motion combo {
  to { opacity: 1 } over 300ms
  with to { x: 0 }  over 500ms ease spring(200, 15)
}

// 混合
@motion complex {
  from { opacity: 0 } over 300ms
  then to { scale: 1.1 }  over 200ms
  with to { x: 20 }       over 300ms    // with 绑定到最近的 then
}

3. 元素挂载 — 用表达式语法，不是字符串！

// ✅ 正确：@enter={expr} — 和 @onClick={handler} 完全一致的语法
<div @enter={fadeIn} @leave={fadeOut}>

// ✅ 内联 tween — 表达式内部解析，编译器完整可见
<div @enter={to { opacity: 1; y: 0 } over 300ms ease easeOut}>

// ✅ Stagger 作为表达式
<ul @enter={stagger(fadeIn, each: 60ms, from: center)}>

// ❌ 错误（之前）：语法藏在字符串里，编译器看不到
// <div enter="to {opacity:1} over 0.3s">

4. 各种触发方式 — 一致的 @attr={expr} 模式

// 生命周期
<div @enter={fadeIn} @leave={fadeOut}>

// 交互
<button @hover={scale(1.05)} @press={scale(0.95)} @focus={glow}>

// 信号绑定
<div @bind-style={cardMotion} @bind-signal={isOpen}>

// 滚动驱动
<section @scroll={fadeIn} @scroll-trigger={top enters 80%}>

// 手势
<Card @drag-horizontal={swipeCard} @drag-threshold={30%}>

// 循环（无限动画）
<Spinner @animate={to { rotate: 360deg } over 1s loop infinite}>

// 多状态映射
<Panel @states={{
  idle:    to { scale: 1;   opacity: 1 }   over 150ms,
  hover:   to { scale: 1.05; opacity: 1 }   over 150ms,
  pressed: to { scale: 0.95; opacity: 0.8 } over 100ms
}}>

5. Stagger — 函数式修饰符

// 命名 stagger
@motion staggeredList {
  stagger(
    from { opacity: 0; y: 20 } to { opacity: 1; y: 0 } over 400ms,
    each: 60ms,
    from: center     // start | end | center | edges | index(N)
  )
}

// 内联在元素上
<ul @enter={stagger(
  from { opacity: 0; y: 20 } to { opacity: 1; y: 0 } over 400ms,
  each: 60ms,
  from: end
)}>

6. 语法完整性检查 — 这个语法 LL(1) 可解析吗？

上下文 第一个 token 唯一确定？ 解析路径
顶层 @motion ✅ → 进入 motion 定义解析
motion 块内 to / from ✅ → 方向 → 属性块 → 时序
motion 块内 then / with ✅ → 组合关系 → 下一个 motion_item
motion 块内 stagger( ✅ → stagger 函数语法
motion 块内 over / ease ✅ → 时序 / 缓动
元素属性 @enter={ ✅ → 表达式（与 @onClick={} 同模式）
@enter 表达式内 to / from / stagger( / ident ✅ → motion 表达式 或 motion 引用
