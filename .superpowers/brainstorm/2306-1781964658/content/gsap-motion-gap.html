🔴 缺口 2：缓动函数缺少 in/out/inOut 方向变体 + 缺失曲线族

// 我们目前只有：
ease: back(intensity: 1.7)       // 默认是 out，但没有显式声明

// GSAP 有完整方向：
backOut / backIn / backInOut
elasticOut / elasticIn / elasticInOut
bounceOut / bounceIn / bounceInOut

// 还有我们完全没有的：
circOut / circIn / circInOut
expoOut / expoIn / expoInOut
sineOut / sineIn / sineInOut

🔴 缺口 3：paused 初始状态

// GSAP: gsap.to(el, { x: 100, paused: true })
// 动画已就绪但不播放，等 .play() 才开始

// 我们缺了：
@motion fadeIn {
  to { opacity: 1 } over: 300ms
  paused: true          // 初始暂停
}



// mount 时不播放，需要 action 中 card.enter.play()

🟡 缺口 7：缓动方向变体太多，需要统一设计

// 方案 A：每种方向独立函数名（GSAP 风格）
ease: backOut(intensity: 1.7)
ease: backIn(intensity: 1.7)
ease: backInOut(intensity: 1.7)

// 方案 B：统一 direction 参数
ease: back(intensity: 1.7, direction: out)
ease: back(intensity: 1.7, direction: in)

// 方案 C：组合通用 ease 前缀
ease: easeOut back(intensity: 1.7)   // 复用 easeOut + 曲线

// → 方案 A 最清晰，和 GSAP 一致
