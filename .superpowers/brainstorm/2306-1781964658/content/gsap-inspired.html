GSAP 启发式设计：Tween 驱动 + 可组合

从"关键帧思维"切换到"tween 思维"——你说终点，它自动插值

❌ CSS 复古风格（之前）
motion fadeIn {
  from { opacity: 0; y: 20px }
  to   { opacity: 1; y: 0 }
  duration: 300ms
  easing: easeOut
}
// 啰嗦、像配置文件
// 无法组合
// 没有表达式能力
✅ Tween 表达式（新方案）
motion fadeIn =
  { opacity: 0→1; y: 20→0 }
  in 300ms ease easeOut

motion scaleUp =
  { scale: 1→1.05 }
  in 150ms ease easeOut
组合运算：then / with / stagger
// ── 顺序编排 ──
motion entrance =
  fadeIn
  then { opacity: 1→0.8; scale: 1→0.95 } in 100ms
  then { scale: 0.95→1.03 } in 100ms
  then { scale: 1.03→1 } in 200ms ease easeOut

// ── 并行 ──
motion combined =
  fadeIn
  with { x: -100→0 } in 300ms

// ── 交错 ──
motion listEnter =
  stagger({ opacity: 0→1; y: 20→0 } in 300ms, each: 60ms)

// ── 循环 ──
motion pulse =
  { scale: 1→1.05→1 } in 1s loop infinite alternate

// ── 从某个方向交错（GSAP stagger from center） ──
motion listFromCenter =
  stagger({ opacity: 0→1; scale: 0.8→1 } in 400ms, each: 50ms, from: center)
复杂场景仍用块语法（需要多 stop 时）
// 表达式不够时，块语法补充
motion bounce {
  0%   { y: 0 }
  40%  { y: -30 }
  60%  { y: -15 }
  100% { y: 0 }
  in 600ms ease easeOut
}

// 两者可混用！
motion intro =
  fadeIn
  then bounce
  then stagger({ y: 0→10 } in 200ms, each: 30ms)
挂载到元素 — 简洁属性
// 生命周期
<div enter=fadeIn leave=fadeOut>

// 交互
<button hover=scaleUp press=squish>

// 信号绑定（状态变化自动过渡）
<div bind=panelMotion signal=isOpen>

// 滚动驱动
<div scroll=fadeIn scrollTrigger="top 80%">

// 手势跟手
<Card drag=swipeCard dragThreshold=30%>

// 交错（直接在元素上）
<ul enter=stagger(fadeIn, each: 60ms, from: center)>
  <li>...</li>
  <li>...</li>
</ul>
