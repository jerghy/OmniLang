Motion 块属性完整规范

每个属性需要同时能编译到 Web（WAAPI/CSS）和 Flutter（AnimationController）

属性总览
@motion example {
  from { opacity: 0; y: 20 }
  to   { opacity: 1; y: 0 }

  // ── 必填 ──
  over 300ms                          // 时长（唯一必填）

  // ── 可选：时序 ──
  ease easeOut                        // 缓动
  delay 100ms                         // 延迟

  // ── 可选：播放控制 ──
  loop 3                              // 循环次数（infinite 无限）
  alternate true                      // 往返交替
  reverse false                       // 反向播放

  // ── 可选：填充 ──
  fill forwards                       // none | forwards | backwards | both
}

1. 时长 & 延迟：时间值

over 300ms           // 毫秒
over 1.5s            // 秒
over 0.3s            // 小数秒

delay 100ms          // 同时间单位
delay 0s             // 默认无延迟
WebWAAPI duration / delay（毫秒）
FlutterDuration(milliseconds: N)

2. 缓动函数：预设 + 自定义 + 物理

// ── 标准预设（两端统一） ──
ease linear
ease easeIn        | ease easeOut        | ease easeInOut

// ── 自定义贝塞尔 ──
ease cubic(0.16, 1, 0.3, 1)       // Web: cubic-bezier(); Flutter: Cubic()

// ── 物理弹簧 ──
ease spring(200, 15)               // tension, friction
ease spring(200, 15, 2)            // tension, friction, velocity

// ── 高级预设 ──
ease back(1.7)                     // 超出再回弹（Web: 用 cubic-bezier 近似 / Flutter: 原生支持）
ease elastic(1, 0.5)               // 弹性
ease bounce                        // 弹跳

// ── 步进 ──
ease steps(5, end)                 // 分步（Web: steps() / Flutter: 自定义 Curve）
WebWAAPI easing + JS spring 模拟（spring/bounce 在 WAAPI 中无原生支持，运行时用 JS 实现）
FlutterCurve 子类 + SpringSimulation

4. 语法位置：motion 块内部顺序
// 规范顺序（编译器可以放松，但建议按此顺序写）：
@motion NAME {
  // ① 帧：from → to / 0% {...} 100% {...}
  from { ... }
  to   { ... }

  // ② 时长（必填）
  over DURATION

  // ③ 缓动
  ease EASING

  // ④ 延迟
  delay DURATION

  // ⑤ 播放
  loop COUNT | infinite
  alternate true | false
  reverse true | false

  // ⑥ 填充
  fill none | forwards | backwards | both
}

// 组成时省略块结构
@motion entrance {
  from { opacity: 0; y: 30 } over 400ms ease easeOut
  then from { opacity: 0; x: -20 } over 300ms
}
// ↑ 每个 motion_item 可以带自己的 over / ease / delay
// 如果省略，继承上一个 motion_item 的值

5. 未解决问题

问题 选项
属性用 ; 还是换行分隔？ 建议换行（和 CSS 风格一致），; 可选用于同行多属性
loop infinite 还是 loop: infinite？ 建议 loop infinite（免冒号，和 ease easeOut 一致）
alternate true 还是 direction alternate？ 建议 direction alternate（更像 GSAP/CSS，支持 normal | reverse | alternate | alternateReverse）
Spring 的 velocity 应该是什么单位？ 建议无单位（GSAP 风格：spring(200, 15, 2)），编译器按平台换算
