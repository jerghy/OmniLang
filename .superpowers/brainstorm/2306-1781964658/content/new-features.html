新增 7 个动画能力

hover 反向 / 手势惯性 / 即时设置 / 颜色插值 / 路径动画 / 共享元素 / 时间线标签

1. Hover 反向：离开时自动倒放

// 默认行为：@hover 进入时 play，离开时自动 reverse（从当前进度倒回去）
<button @hover={scale(1.05)}>          // 进入放大，离开缩回去

// 可以禁用反向
<button @hover={scale(1.05)} @hover-reverse={false}>

// 也可以用不同的离开动画
<button @hover={scaleUp} @unhover={scaleDown}>

// 编译器逻辑：
// @hover → 绑定 mouseenter/mouseleave（Web）或 onHover（Flutter）
// enter → play()   leave → reverse()

2. 手势惯性：松手后减速滑行

// momentum: friction 值越小减速越快，1.0 永远不停
<Card @drag-horizontal={swipeCard}
      @drag-momentum={friction: 0.95}
      @drag-velocity-max={2000px}>      // 速度上限

// 更真实的物理：
<Panel @drag-vertical={panelSlide}
       @drag-inertia={true}               // 自动用合理默认值
       @drag-boundary={0, panelHeight}>  // 惯性衰减到边界内

// 松手时 velocity 传给动画回调
@motion swipeCard {
  onStart: { startVelocity = $velocity }  // $velocity 来自手势
  to { x: $direction * screenWidth } over: 500ms
  ease: spring(tension: 100, friction: 10, velocity: $velocity)
}

3. 即时设置：set —— 不动画的属性赋值

// set 块：瞬间赋初始值，无过渡
@motion flyIn {
  set { opacity: 0; y: 50px; scale: 0.9 }    // 瞬间归位
  then to { opacity: 1; y: 0; scale: 1 } over: 400ms ease: easeOut
}

// 也用于清理
@motion cleanup {
  set { opacity: 0; x: 0; y: 0 }    // 所有属性瞬间重置
}

// 内联
<div @enter={
  set { opacity: 0; x: -100px }
  then to { opacity: 1; x: 0 } over: 400ms
}>

4. 颜色插值模式：HSL / OKLCH / RGB

@motion rainbowShift {
  to { color: #ff0000; backgroundColor: #00ff00 } over: 1s
  colorSpace: hsl          // 过亮色，不是灰色！
                           // hsl（色相旋转）| rgb（直线）| oklch（感知均匀）
}

// 不同模式产生完全不同的中间色
// rgb:     红 → 灰 → 绿（沉闷）
// hsl:     红 → 黄 → 绿（鲜艳）
// oklch:   红 → 橙 → 绿（最自然）
WebWAAPI 不支持 HSL 插值 → 运行时 JS 在每一帧手动插值
FlutterColorTween 或用 HSLColor.lerp

5. 路径动画：元素沿路径运动

// 用 SVG path 语法定义运动轨迹
@motion followPath {
  to { offset: 1 } over: 2s ease: easeInOut
  path: "M 0,0 C 50,-50 100,50 200,0"   // SVG 路径字符串
}

// 或者用贝塞尔控制点
@motion curvePath {
  to { offset: 1 } over: 2s
  path: cubic(x1: 0, y1: 0, x2: 100, y2: -50, x3: 200, y3: 0)
}

// 元素上
<Ball @enter={followPath}>

// 路径 + 旋转跟随
@motion pathWithRotate {
  to { offset: 1; rotate: 360deg } over: 2s
  path: "M 0,0 Q 100,-100 200,0"
  pathRotate: true              // 元素自动朝向路径方向
}
Weboffset-path + offset-distance（CSS）或 WAAPI
FlutterPath + PathMetric.getTangentForOffset

6. 共享元素过渡：Hero 动画

// ── 定义共享元素（跨页面/组件） ──
// 页面 A
<img src={product.image} @hero="product-image">

// 页面 B（不同的布局位置，同一张图）
<img src={product.image} @hero="product-image">

// 页面切换时 → 图片从 A 的位置平滑飞到 B 的位置
// 编译器自动生成 FLIP 动画 + WAAPI / Hero widget
Web记录旧位置 → FLIP → WAAPI 插值 transform
Flutter直接编译为 Hero(tag: "product-image", child: ...)
// 高级：自定义共享过渡动画
@hero product-image {
  over: 400ms
  ease: spring(tension: 200, friction: 15)
}

<img @hero="product-image" @hero-transition={product-image}>

7. 时间线标签：命名关键点

@motion complexReveal {
  from { opacity: 0; y: 40px } over: 300ms
  label "fadedIn"                               // ← 这个时刻叫 "fadedIn"

  then to { scale: 1.05 } over: 150ms
  label "popped"

  then to { scale: 1 } over: 200ms
  label "done"
}

// 通过标签 seek
action replayPop {
  card.complexReveal.seek("popped")   // 直接跳到 "popped" 的位置
  card.complexReveal.play()           // 从那里继续播
}

// 标签也可以用于回调
@motion entrance {
  from { opacity: 0 } over: 300ms
  label "visible" onEnter: { startTracking() }  // 到达此标签时触发
  then to { y: 0 } over: 200ms
}
