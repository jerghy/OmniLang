补充：可控制的动画 & 回调

动画不只是"播放"——还要能被外部输入驱动、能回调

1. 动画回调：onStart / onUpdate / onComplete / onRepeat

@motion fadeIn {
  to { opacity: 1; y: 0 } over: 300ms ease: easeOut

  onStart:    { isAnimating = true }
  onUpdate:   { animProgress = $progress }   // $progress 是魔法变量，0→1
  onComplete: { isAnimating = false; count += 1 }
  onRepeat:   { repeatCount += 1 }
}

// 也可以引用函数
@motion fadeIn {
  to { opacity: 1 } over: 300ms
  onStart: startAnim
  onComplete: finishAnim
}

2. 可控制的动画：driven-by —— 外部输入驱动进度

// 核心：动画进度不由时间驱动，而由外部表达式驱动（0→1）

// ── 信号驱动 ──
signal scrollProgress: float = 0
<div @animate={fadeIn} @driven-by={scrollProgress}>
// scrollProgress: 0 → 动画在 0%
// scrollProgress: 1 → 动画在 100%
// 中间值 → 动画停在对应进度

// ── 指针驱动 ──
<div @animate={fadeIn} @driven-by={mouseX / containerWidth}>

// ── 滚动驱动（driven-by 的便利封装） ──
<div @scroll={fadeIn}                          // scroll 自动生成 0→1 进度
     @scroll-start="top 80%"                    // 滚动到此处 → 进度 0
     @scroll-end="bottom 20%">                  // 滚动到此处 → 进度 1

// ── scrub 模式：滚动位置平滑跟随 ──
<div @scroll={fadeIn}
     scrub: 0.5                                 // 0 = 直接跟随, >0 = 平滑延迟（秒）
     @scroll-start="top bottom"
     @scroll-end="bottom top">

// ── 手势 scrubbing ──
<Slider @drag-horizontal={slideAnim}
        @drag-scrub={true}
        @drag-bounds={0, containerWidth}>

3. 动画控制 API：程序化操控

// 元素上声明动画后，可通过 ref 获取控制句柄
<div ref:card @enter={fadeIn} @leave={fadeOut}>

// 在 action 或事件中操控
action playCardAnim {
  card.fadeIn.play()           // 从头播放
  card.fadeIn.pause()          // 暂停
  card.fadeIn.resume()         // 继续
  card.fadeIn.reverse()        // 反向播放
  card.fadeIn.seek(0.5)        // 跳到 50% 进度
  card.fadeIn.progress = 0.5   // 直接设进度
  card.fadeIn.kill()           // 终止并清除
}

// 组合控制
action sequenceDemo {
  logo.entrance.play()
  await logo.entrance.complete   // 等待动画完成
  cards.listIn.play()
}

4. 动画状态查询

// 每个动画实例暴露只读状态
signal isPlaying: bool = card.fadeIn.playing
signal progress: float = card.fadeIn.progress     // 0→1
signal currentLoop: int = card.fadeIn.iteration

// 可在条件中使用
@if card.fadeIn.completed {
  <div>动画完成</div>
}

5. 完整分类总结

驱动方式 触发属性 进度来源 典型场景
🕐 时间驱动 @enter @leave @hover @press 时钟 入场/退场/交互反馈
🔄 循环驱动 @animate 时钟 + loop spinner / 脉冲 / 呼吸灯
📜 滚动驱动 @scroll + scrub scroll 位置 → 0→1 视差 / 滚动揭示 / 进度条
👆 手势驱动 @drag-horizontal + @drag-scrub 手指/鼠标位移 滑动删除 / 拖拽排序
📡 信号驱动 @driven-by 任意 signal (0→1) 自定义进度条 / 音频可视化
🎮 程序驱动 ref.anim.play() .seek() 代码 API 游戏逻辑 / 复杂编排
