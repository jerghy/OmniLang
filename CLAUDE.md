## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature-slug>/` in this repo (local-markdown tracker). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, label string equals role name: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + ADRs in `.architecture/decisions/adrs/`. See `docs/agents/domain.md`.
