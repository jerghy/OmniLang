关于怎么转到设计界面：
现在处于架构界面，可以右键具体的泡泡，选择“设计”；或者双击最底层的元素泡泡。如果不是最底层，双击会进入该泡泡内部。

关于代码和 Store 代码的分层：
代码可以按函数作为子泡泡，或者将包含多个函数的函数集作为大泡泡来实现分层。Store 类似，但可以更分散，
设计页面
设计页面具体为标签页设计，一个标签页对应一个omni代码文件。标签页内包含双层画布，分为 Z 轴的里外两层：外层是界面设计，内层是代码设计。
┌──────────────────┬──────────────────────────────────────────────┬────────────┐
│ 层 │ 内容 │ 作用 │
├──────────────────┼──────────────────────────────────────────────┼────────────┤
│ 上层（界面设计） │ 该组件的真实 DOM 渲染预览 │ 所见即所得 │
├──────────────────┼──────────────────────────────────────────────┼────────────┤
│ 下层（代码设计） │ signal / computed / fn / event 等节点 + 连线 │ 逻辑骨架 │
└──────────────────┴──────────────────────────────────────────────┴────────────┘

交互：
- 单击选中 → 右侧属性面板
- 双击组件 → 钻入下层（上层缩小到一角，下层浮现节点图）
- 双击 fn 节点 → Monaco 编辑器替换下层
- 面包屑导航回退

关于双向同步保存的 Omni 代码和数据
按照设计文档，是用注释来告诉解析器怎么解析到poiesis。但其实整个poiesis编辑的项目有很多其他数据需要保存，我觉得其实可以大部分数据就直接存到项目根目录中一个 json 文件，在omni代码文件中每个代码块前必须有一行解析标签，并在json文件中有对应数据，其中 JSON 保存的数据就是一些poiesis数据，真正的有关编程界面代码的数据都可以从omni代码中解析
