# Poiesis Class 编辑器视觉化重构

> 日期: 2026-07-08
> 状态: 设计完成（待进入实现计划）
> 关联: `2026-07-07-poiesis-style-panel-design.md`（第 3.4 节细化 + 重设计）

## 1. 核心理念

当前 Class 编辑器采用表单式属性行（label = input），缺乏设计工具感。本设计将其重构为**视觉化操控面**：专项属性卡片 + 可折叠分组 + 内嵌实时预览，对标 Figma/Webflow 的右侧面板体验。

## 2. 整体布局

三区模式，状态驱动：

### 2.1 常态（三栏）

```
┌─ 左侧 Class 列表 ──┐ ┌─ 中间属性编辑 ────────┐ ┌─ 右侧预览 ───────┐
│ Classes (180px)     │ │ 伪类标签              │ │ (单击卡片时出现)  │
│ ▪ card              │ │ 卡片 + 折叠组          │ │                   │
│ ▪ class-1           │ │ (纵向单列)             │ │                   │
│ [+ Add Class]       │ │                       │ │                   │
└─────────────────────┘ └───────────────────────┘ └───────────────────┘
```

- 左侧 180px，中间 flex: 1，右侧预览仅在单击卡片时出现（~280px）

### 2.2 聚焦模式（双击卡片）

```
┌─ 左 48px ──┐ ┌─ 聚焦预览 ────────────────────────────────┐
│ ☰          │ │                      [div▼]  [退出聚焦 ×]  │
│ card        │ │                                             │
│ ★           │ │     元素全尺寸预览 + 拖拽操作               │
│             │ │                                             │
│             │ │  ┌─ 浮动卡片 ──────────┐                   │
│             │ │  │ (当前激活的卡片控件)  │                   │
│             │ │  └────────────────────┘                   │
└─────────────┘ └─────────────────────────────────────────────┘
```

- 左侧自动变窄至 48px，仅显示 class 名称竖排 + ☰ 展开按钮
- hover 左侧可临时展开完整 class 列表
- 预览区全尺寸渲染元素，可拖拽边缘/角落直接操作
- 浮动卡片显示当前操作的属性控件
- Esc 或 × 退出聚焦，回到常态

## 3. 伪类标签页

保留顶部标签页（用户选择方案 A）：

```
[Base] [:hover] [:focus] [:active] [:disabled] [:focus-visible] [+]
```

- 切到某标签 → 属性区显示该状态的覆盖值
- 已覆盖的属性带紫色圆点标记
- 继承自 Base 的属性灰色显示
- `+` 打开更多伪类下拉（focus-within, visited, placeholder, first-child 等）

## 4. 专项属性卡片

卡片是核心创新——将常用属性组合成可视化操控面，替代逐条属性行。

卡片的三种状态：
- **折叠** — 标题 + 当前值摘要（单行）
- **展开（单击）** — 完整编辑控件 + 小预览
- **聚焦（双击）** — 全屏预览 + 浮动卡片 + 直接拖拽操作

### 4.1 尺寸卡

折叠摘要：`300 × 200`

展开：
```
┌─ 尺寸 ───────────────────────────────── ▼ ──┐
│                                               │
│  W  [300 ▤]  [px ▼]         🔗 等比         │
│  H  [200 ▤]  [px ▼]                         │
│                                               │
│  ┌─ 预览 ──────────────────────────────┐    │
│  │              ↕ 200                   │    │
│  │       ┌──────────────┐              │    │
│  │  ←300→│    W × H     │←── 可拖拽 ──→│    │
│  │       └──────────────┘              │    │
│  └──────────────────────────────────────┘    │
└──────────────────────────────────────────────┘
```

- W/H 各一个 scrub input，click+drag 左右调值
- 🔗 等比锁定：拖拽一边时另一边按比例自动计算
- 预览中间矩形可拖拽四边和四角
- 单位：px / % / auto；选 auto 时该项变灰不可拖拽

聚焦模式：直接拖拽元素四角等比缩放、拖拽边缘单向调宽/高，Shift=等比。

│  └──────────────────────────────────────┘    │
│                                               │

折叠摘要：`P:16px M:0`

## 6. HUD 取色器

用于非背景卡的颜色属性（边框颜色、文字颜色等），点击色块弹出。

### 6.1 布局

```
┌─ 取色 ────────────────────────────┐
│  ┌─ HSV 平面 ────────────────┐    │
│  │         ○                  │    │
│  └────────────────────────────┘    │
│  ┌─ 色相条 ─────────────────┐    │
│  │ ██████████████████████████│    │
│  └────────────────────────────┘    │
│  ┌─ 透明度条 ───────────────┐    │
│  │ ░░▓▓████▓▓░░      100%   │    │
│  └────────────────────────────┘    │
│  [#6366f1]  [HEX ▼]  💧          │
│  ┌─ Tokens ─────────────────┐    │
│  │ ■ primary ■ surface ...  │    │
│  └────────────────────────────┘    │
│  ┌─ 最近使用 ───────────────┐    │
│  │ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■    │    │
│  └────────────────────────────┘    │
└────────────────────────────────────┘
```

### 6.2 交互规则

- 定位：色块下方优先，空间不够则上方；水平 clamp 到视口
- 拖拽 HSV 平面 → 实时更新，预览即时刷新
- 拖拽色相条 → 只改色相
- 拖拽透明度条 → 色块显示棋盘格底纹
- HEX 输入失焦纠正非法值
- 点 token 色板 → 选中颜色 + 🔗 绑定
- 点 HUD 外部 → 关闭、提交（Cmd+Z 可撤销）
- Esc → 关闭、不提交、恢复原值

### 6.3 Token 色板

- 只显示 `tokenType === "color"` 的 token
- 色块 20×20，圆角，hover tooltip 显示名称 + 使用次数
- 当前已绑定的 token 边框高亮

## 7. Scrub Input（通用数值拖拽组件）

所有数值输入的统一交互：

| 操作 | 效果 |
|------|------|
| 悬停 | 光标变 `ew-resize` |
| click + 拖拽 | 左右拖拽调值，每像素 = step |
| Shift + 拖拽 | 粗调，×10 |
| 点击不放 | 进入编辑模式（选中全部文本 + 键盘输入） |
| ↑↓ 键 | ±1 |
| Shift + ↑↓ | ±10 |
| Enter | 确认 |
| Esc | 恢复原值 |
| 拖拽结束 | 触发 onChangeEnd（单次撤销点） |

## 8. Token 绑定机制

- 颜色属性 = 色块即是取色入口，取色面板内含 token 色板
- 非颜色属性（字号/间距）= 🔗 按钮 → 搜索式 token 下拉
- 🔗 亮蓝 = 已绑 token，灰 = 未绑
- 点 🔗 再选 token → 绑定
- 点 × → 解除绑定，恢复原始文本值

## 9. 预览面板 (ClassPreview)

- 单击卡片时在属性区旁边出现（~280px）
- 显示实际 HTML 元素（div/p/button 等），下拉切换元素类型
- 实时渲染当前 class 的所有样式
- 聚焦模式下全尺寸预览
- 尺寸卡激活 → 预览可拖拽边缘调节宽高
- 伪类模拟：hover 悬停 → 显示 :hover 覆盖值

## 13. 已知风险

| 风险 | 缓解 |
|------|------|
| Scrub input 在 Windows 下鼠标事件可能不可靠 | 全局事件监听（window mousemove/up），不用元素级事件 |
| HSV 面板渲染性能 | CSS gradient overlay 实现，非 canvas，硬件加速 |
| 卡片数量增加导致纵向滚动多 | 默认折叠，折叠摘要即够用；聚焦模式省去滚动 |
| token 色板数据同步（新增 token 后 HUD 未更新） | 直接从 store 读取，总是最新 |
| 聚焦模式覆盖全屏，与其他 UI 冲突 | z-index 管理，Esc 退出 |
