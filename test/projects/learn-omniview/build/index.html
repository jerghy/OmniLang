使用 then/with 连接器（无 start: 修饰符）作为对比基准

start: 定位修饰符一览

start: "withPrev" 与上一项同时开始 → B 与 A 同时执行
start: "after" 在上一项结束后开始（默认行为） → C 在 B 之后执行
start: "overlap(N)" 与上一项重叠 N 毫秒 → D 在 C 结束前 150ms 开始
start: "afterPrev(N)" 上一项结束后 N 毫秒开始 → E 在 D 结束后 200ms 开始
start: "withOffset(N)" 与上一项同时开始，但偏移 N 毫秒 → F 与 D 同时但晚 100ms 触发
start: "absolute(N)" 在时间线绝对时间 N 毫秒处开始 → G 在 1200ms 处执行

💡 时间线定位语义

  • start: 修饰符控制时间线项目的 相对/绝对定时
  • 未指定时默认行为是 start: "after" （在上一个项目完成后开始）
  • then 连接器等价于 start: "after" 顺序执行
  • with 连接器等价于 start: "withPrev" 同时执行
  • start: 提供 then / with 之外的细粒度控制

CSS Custom Properties (CSS Variables)

演示编译器对 --* 声明、 var() 引用、内联静态/动态 CSS 变量的完整支持

① Style 块声明 --* + var() 引用

Style 块内部声明 --primary 、 --bg 等自定义属性， 然后用 var() 引用。这是编译器中 parse_css_property_name() 解析 -- 前缀的常规路径。

var(--primary)
var(--primary-alt)
background: var(--surface)
border: var(--border-color)

② 内联样式静态 CSS 变量

在 style: &#123; --name: "value" &#125; 中直接写 -- 属性。 编译器代码生成将 -- 属性用 el.style.setProperty("--name", value) 输出，而非普通的 el.style.prop = value 。

--box-bg: "#e0e7ff"
--box-radius: "16px"
--box-radius: "50%"

③ 内联样式动态 CSS 变量（信号 → setProperty）

传递 信号引用 给 --* 属性。编译器自动生成 __omni_effect(() => el.style.setProperty("--name", signal.value)) 。 这是新增的 $signal JSON 标记代码路径。

当前 accent:

生成的 JS: setProperty("--accent", accentColor.value)

④ CSS 变量级联 + Motion 驱动

外层设 --accent-h ，内层用 var(--accent-h) 计算衍生色。 配合 交替动画驱动 hue 值变化。

hue = °

内层用 var(--accent-h) 通过 CSS hsl() 计算色值

221° 260° 300° 340°

编译器技术要点

  • parse_css_property_name() 在 view.rs:1134 检测 -- 双短横前缀
  • emit_style_assignment() 在 omniview.rs:692 对 -- 属性用 setProperty() 而非直接赋值
  • Style 块中 --name: value 以 StyleValue::Ident / HexColor / Dimension 存储在 AST
  • 内联 style: &#123; --name: signal &#125; 通过 $signal JSON 标记生成响应式代码
  • 测试覆盖： css_custom_property_test.rs （解析 + 静态内联 + 动态内联）

Theme with CSS Variables

父元素注入 --theme-* CSS 变量（来自 ThemeStore 信号）， 子元素用 var() 继承。切换主题时触发 setProperty() 响应式更新。

CSS Variable Cascading

background、color、border-color 均通过 var(--theme-*) 从父级继承。主题切换时所有卡片同步变化。

BG: var(--theme-bg) TX: var(--theme-text) PR: var(--theme-primary)

Composition with calc()

calc(var(--theme-border-w) * 2px) 动态计算边框宽度。 点击按钮切换 --theme-border-w 值。

Transform via CSS Variable

transform: scale(var(--theme-scale)) 。 信号值通过 setProperty("--theme-scale", boxScale.value) 驱动。

Theme Palette via var()

--theme-bg
--theme-primary
--theme-text
--theme-muted

当前主题: · 切换次数: · 代码路径: setProperty()

💡 关键设计模式

  • CSS 变量级联：在组件根元素一次性注入 --theme-* ，所有子元素用 var() 自动继承
  • 信号 → setProperty：编译器为 style: &#123; --var: signal &#125; 生成 __omni_effect(() => el.style.setProperty("--var", signal.value))
  • 主题切换只需更新 ThemeStore 的 getter，CSS 变量自动响应
  • 对比 ThemeSwitcher：后者每个元素单独绑定 style: &#123; color: ThemeStore.currentText &#125; ，CSS 变量版只需在根元素设一次
