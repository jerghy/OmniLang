# Spec：Poiesis 阶段 v1 — 统一画布 + 睡/醒 + 语境面板 + 底栏 + 源节点

Status: ready-for-agent
Type: spec
Source: 设计稿 docs/design/poiesis-visual-app-editor-design.md §17（08-11 定稿，拍板 #47-53）+ 08-11 grill 会话（六轮收敛）

## Problem Statement

Poiesis 现在是"意图语言的文本编辑器"：**设计画布（元素，WASM 渲染）与 CodeFlow 逻辑画布（fn 图，ReactFlow）是互斥的两块**——双击元素才进逻辑画布（设计层 `display:none` + 缩放隐藏），看不到"数据和界面在一起"的样子；事件绑定靠写/引用函数；属性编辑在固定的右栏。设计稿（探路轨）已定稿"一对象、无模式、睡/醒呼吸"的愿景（§3/§15），但编辑器现状与愿景差距巨大——两块画布各自为政，用户每次在"设计视图"和"逻辑视图"之间来回切换，数据与界面永远不在一张图上。

用户裁定：**先实现一个阶段**——把两块画布打通为一个，用"睡/醒"设计组织它。

## Solution

**一块画布、两种呼吸。** 打开组件只有一块画布：**睡态**（默认）= 干净的设计画布，只有元素、摸到就改（现状交互全部保留）；点角落**呼吸点** → **整页醒** = 逻辑层浮现——fn 节点、源节点（store/signal 卡片）、元素接口手柄、连线，全部叠加在同一块画布上（视口同步，元素原地不动）。事件/数据绑定由**弹出的语境面板**完成（替代右栏）：选中元素 → 面板浮在旁边（[行为][内容][结构] 标签）；Shift 多选 → 第二个元素局部醒 + 副面板（仅 [内容]）；取消选中 → 睡回，接口留**来源印记**。睡态工具住进**底栏**（[组件库][数据节点] 两件套）。绑定全部走现有语法落盘（语法零变更）：事件 = 行为卡 → `@onClick` + 自动生成 fn；数据五类槽 = `{expr}`/`bind:value`/`@for`/`@if`/属性；元素间连线 = **自动中转 signal**（`<源>_<槽位语义>` 命名、同槽复用、数据区独立分组）。

按里程碑交付：**M1 打通地基 → M2 睡态工具 → M3 醒态绑定**，每里程碑单独验收。

## User Stories

1. 作为用户，我打开一个组件，看到只有我的页面元素（睡态），摸到就能改——现状的设计体验不能倒退
2. 作为用户，我想在画布角落看到一个小脉搏（呼吸点），点一下整页醒（逻辑浮现），再点一下睡回（界面干净）
3. 作为用户，醒来后，我的 fn 节点（数据处理）以卡片形式浮现在画布上，和元素在同一块画布里，不用再"进另一个画布"
4. 作为用户，醒来后，store/signal 以源节点卡片出现在画布一角（数据区），我能看到它们的名字和当前值
5. 作为用户，醒来后，元素的接口（文本/值/列表/条件/属性）以手柄形式长在元素上，睡态时手柄不出现
6. 作为用户，我想选中一个元素时，语境面板浮在它旁边（而不是固定右栏），元素移动时面板跟着走
7. 作为用户，面板旁边放不下时，它自动弹向另一侧/上方；我也可以手动把它拖走
8. 作为用户，什么都不选时，面板收成一个小浮标，不挡画布
9. 作为用户，我在面板里能看到 [行为][内容][结构] 三个标签（[样子] 本阶段不出现）
10. 作为用户，我点 [内容] 标签时应用自动醒——我想接数据的那一刻，不用先想"我要先醒一下"
11. 作为用户，我可以在 [内容] 标签里看到这个元素的所有数据槽（文本内容/输入值/列表/显示条件/属性），已绑的显示来源印记
12. 作为用户，我点一个槽 → 从来源清单里点选一个来源（源节点 / fn 出口 / 醒着的元素），绑定即完成（点名式绑定）
13. 作为用户，我可以在 [行为] 标签里用行为卡绑定事件：`当 [点击] → [把] [计数器] [加 1]`，不用写任何代码
14. 作为用户，行为卡里的动词是常用词（点击/提交/删除/编辑/取消…最小集起步），我不用学编程术语
15. 作为用户，我可以用 Shift 选中第二个元素，它也醒来，旁边弹出第二个面板（只有 [内容] 标签），两个面板最多并存 2 个
16. 作为用户，我可以从 A 元素的"值"手柄拖线到 B 元素的"文本"手柄（ReactFlow 节点式拉线），松手即绑定——元素间的数据流像节点图一样直观
17. 作为用户，输入框的值接到标题文本后，我在输入框打字，标题实时变（响应式，不是快照）
18. 作为用户，我取消选中后，元素睡回：手柄和线收起，接口上留小徽章"来自 报名记录"（来源印记）
19. 作为用户，我悬停/选中一个已绑定的元素时，它吃的那几条线亮回来，我随时能看数据从哪来
20. 作为用户，我在底栏看到 [组件库]，点开可以拖元素到画布（原来的左侧组件面板搬到了这里）
21. 作为用户，我在底栏看到 [数据节点] 开关，点一下源节点卡片显示/隐藏（醒态下）
22. 作为用户，我点开一张源节点卡片可以改它的值（store/signal 值），界面当场演——设计条件渲染就是拨数据
23. 作为用户，编辑器为我自动创建的元素间连线 signal 出现在数据区一个独立的"自动连线"分组里，跟我自己写的 signal 分得清清楚楚
24. 作为用户，自动连线 signal 的名字我能看懂（`nameInput_value` = nameInput 的值），需要时我可以改名
25. 作为用户，同一个输入框的值喂给多个目标时，只建一个 signal、多处复用——我不会看到一堆重复的名字
26. 作为用户，我断开一条自动连线且没有别处引用它时，这个自动 signal 被回收，不留垃圾
27. 作为用户，我保存后重新打开，所有绑定（事件/数据槽/元素间连线）原样回来——往返闭环不丢
28. 作为用户，我不需要再双击元素"进入逻辑画布"——那块画布消失了，逻辑就在同一块画布上
29. 作为用户，我醒着的时候也能改样式（睡/醒是数据流动开关，不是模式）——改样式不会被锁住
30. 作为用户，fn 节点的内部逻辑我直接在画布上编辑（节点+线），不再有双击打开的卡片编辑器

## Implementation Decisions

> 权威契约：设计稿 §17。无文件路径（防过时）。里程碑 M1→M2→M3，逐个验收；M1 开工先做视口同步原型验证（最大技术赌注）。

### 跨里程碑

- **画布架构（打通）**：设计层 DOM 渲染（WASM 元素树）**保持不动**；醒态在其上**叠加**一个常驻的 ReactFlow 逻辑层（fn 节点 + 源节点 + 元素手柄 + 边）。技术依据：设计元素是 CSS 流式布局、ReactFlow 节点是自由坐标——元素整体迁入 ReactFlow 会砸流式布局；叠加层 + 手柄按元素实际渲染位置长在元素上，正是设计稿 §15.3"端口长在元素上"。
- **视口同步**：zoom/pan 单一真相 = 现有画布视图 store，驱动 ReactFlow viewport（`setViewport` 镜像）；两引擎并存但用户只见一块画布。删除：双击进出逻辑画布模式、TopLayer 缩放隐藏互斥、DesignPreviewNode 只读快照伪节点。
- **睡/醒状态机**（store 级，单一状态源）：
  ```
  awake: boolean                    // 整页醒（呼吸点）
  awakeArea: ElementId[]            // 醒区 = 选中集合（Shift 多选建立；空选清空）
  呼吸点          → awake 翻转；awakeArea 清空
  选中元素        → 开主面板；[内容] tab → awake = true（自动醒）
  Shift 追加选中  → 加入 awakeArea；开副面板（仅 [内容]）
  取消选中        → 清空 awakeArea；元素睡回（留印记）
  逻辑层可见      ⇔ awake || 元素 ∈ awakeArea（fn 节点/源节点/手柄/边随醒处）
  源节点可见      ⇔ awake（本阶段；睡态不可见）
  ```
- **睡/醒是数据流动开关**，正交于样式编辑：醒态下样式编辑路径（现设计画布交互）全部保持可用。
- **undo 兼容**：所有新状态转换与绑定操作走现有 undo 体系（快照/回放语义保持一致），不另起机制。
- **保存往返不变**：绑定落盘后走现有 emitter/parser 闭环；project.json v3 形状沿用（自动 signal 是普通 signal，不发明新节点类型）。

### M1 打通地基

- **语境面板**（新浮动组件，替代右栏 ContextInspector，右栏删除）：
  - 浮动定位：选中元素旁，跟随元素移动，放不下换侧/上方，可手动拖走；空选收成小浮标
  - **主面板**：[行为][内容][结构] 三标签（[样子] 不出现）；**副面板**：仅 [内容]；**最多 2 个面板**（主 + 副）
  - [结构] 标签承接现有 ContextInspector 的属性编辑能力（迁移不重写）
  - [内容] 标签本阶段 = 槽位清单 + 点名绑定 UI（见 M3）+ 来源印记展示
- **呼吸点**：画布角落小脉搏按钮，整页睡/醒切换（状态机见上）。

### M2 睡态工具

- **底栏两件套**：[组件库]（点开弹出面板，承载现有组件面板 ComponentPalette 的拖拽能力，从左侧搬入）+ [数据节点]（源节点显隐开关）。左栏只留组件树。
- **源节点**：store/signal 简化卡片（图标 + 名 + 当前值）；数据区（画布一角）自动排布、可拖动；由 [数据节点] 开关控制显隐（醒态下有效）。
- **改值调试**（临时调试模式基础版）：醒态点源节点卡片 → 改值浮层 → 值写入 → 画布预览当场演（走现有 store 值更新 → WASM 重编译管线）。变量/数据页源节点与账本/小灯形象后置。

### M3 醒态绑定

- **行为卡（事件）**：`当 [事件] → [动作] [参数]` 表单；最小动词集 ~10 个起步（点击/提交/删除/编辑/取消/加/减/跳转…），G3 词库后置扩充。落盘：`@onClick` 等语义事件 + **自动生成 fn**（用户不写不看；面板改 fn 跟着改）——语法零变更。
- **五类槽点名绑定**（[内容] 标签）：文本 `{expr}` / 输入 `bind:value` / 列表 `@for` / 条件 `@if` / 属性——点槽 → 选来源清单（源节点 / fn 出口 / 醒着的元素），落盘全是现有语法。
- **手柄拖线**（ReactFlow 节点式）：元素接口手柄（源/目标双向可连）+ 拖线即绑定；与点名**两路并存**（同一绑定两种操作路径）。
- **元素间连线 = 自动中转 signal**（语言事实依据：`{ref.value}` 是快照非响应式、bind:value 只绑 signal——语言无元素直接引用，signal 中转是唯一响应式路）：
  - 命名 `<源元素>_<源槽位语义>`（`nameInput_value` / `checkbox_checked`）；无 @ref 时源名 = 类型+序号（`input_2`）；生成后可改名
  - **同槽复用**：同一 (源元素, 槽位) 的 N 条连线 = 同一个 signal（不重名、不建多条）
  - 数据区**独立分组"自动连线"**，与用户 signal 分排
  - **回收**：断开连线且无其他绑定引用 → 删除该 signal
  - 落盘形状：值型源 = 源元素 `bind:value={sig}`；目标端 = `{sig}` / `@if` / `@for` 引用
  - 线源限三类：值型控件（input/textarea/select/slider）、源节点（store/signal）、fn 出口；显示元素当源后置
- **来源印记 + 亮线**：绑定完成、线收起后接口上留"来自 X"小徽章；悬停/选中 → 相关线亮回。

## Testing Decisions

- **好测试的定义**：只测外部行为——store 状态转换的结果、emit/parse 往返后的形状、组件渲染出的 UI 交互结果；不测实现细节（不 mock 内部函数、不断言内部调用）。
- **主缝 ① store 切片**（回归风险最高处）：睡/醒状态机（呼吸点翻转、[内容] 自动醒、Shift 醒区、取消睡回）、面板可见性规则（主/副/浮标/最多 2 个）、自动 signal 生命周期（创建/同槽复用/回收）、改值写入。先例：`src/store/__tests__/`。
- **主缝 ② codegen 往返**：自动 signal 落盘闭环——emit 后 parse 形状不变（signal 名、绑定端、分组归属）；事件行为卡落盘（`@onClick` + 自动 fn）往返。先例：`src/services/codegen/__tests__`（CodeFlow 图往返测试同款风格）。
- **缝 ③ 组件测试**：呼吸点、语境面板（浮动/标签切换/副面板/浮标）、底栏两件套、源节点卡片渲染与交互（@testing-library/react）。先例：`src/components/canvas/code/*/__tests__`、`src/components/panels/__tests__`。
- **缝 ④ 实机验证**（不进 CI）：画布叠加视觉效果、视口同步、拖线手感、面板跟随/避让——Victauri MCP 驱动（dom_snapshot/eval_js/screenshot），每个里程碑验收时走一遍完整剧本。

## Out of Scope

- 六接口形状可视化（圆点/双竖线/菱形/方块）、拖线交互规格（换源/断开/误连反馈）、线的流动动画
- 局部唤醒细化（[内容] 自动醒 → 只醒选中元素）——本阶段 [内容] 自动醒 = 整页醒（已记 todo）
- 行为卡动作词库 G3 扩充（最小动词集起步即可）
- 变量/数据页源节点 + 账本/工作台/小灯/便签形象
- 调试窗口（独立真窗口，§3 第三态）、测试数据集（活体模特）、换页发射端/接收端实施、应用树/呼吸灯/骨架视图、多应用果园
- 元素当线源（显示元素 → 其他元素的源）后置
- CodeCardEditor 删除后的替代编辑体验深化（本阶段 = 画布节点编辑，够用即可）
