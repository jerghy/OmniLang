# 05 — 边界裁决细则与语言完整性原则

Type: grilling
Status: open
Blocked by: 01, 02, 03

## Question

三判据边界裁决（用户拍板）的**执行细则**与「语言承诺 = 行为」完整性的处置原则——所有维度裁决共用的判例模板。

## 决议内容

1. **三判据执行判例**：每个判据如何判定？
   - 跨目标一致表达：谁能裁决（三目标 codegen 既有经验/研究证据）？"一致"到什么程度（floor 对等 ADR-021）？
   - 编译器理解意图：怎么算"理解"（机制级 vs 功能设计级——2026-08-08 实证三分层）？透传算不算？
   - 真实语料需求：证据标准（learn-omniview/基准应用/poiesis 用户场景）？语料缺位的判例（#83 motion-in-@for 先例）？
2. **裁决模板**：每维度统一用同一模板（能力项 × 三判据逐项打分 → 进语言/留生态/不支持 + 证据）
3. **半实现信号处置原则**：语言承诺但行为是桩的信号（form.submitting 恒 false、Flutter form.valid 恒 true、@load 仅 Array）——基线是否要求「承诺 = 行为」？（选项：a) 要求补齐行为才入基线；b) 明确标注 v0 边界随批次补齐；c) 移除承诺）
4. **留生态的承接方式**：裁决为「留生态」的能力如何在文档中表达（记录为语言边界 + 目标生态映射指引）？
