Type: grilling
Status: open
Blocked by: 04, 05

## Question

**样式系统**能力的边界裁决与设计方向——按 05 定稿的裁决模板执行。

覆盖能力项与现状（2026-08-09 实证）：
- **复杂选择器静默跳过零诊断**（真实缺陷）：parser 对不支持的剩余选择器部分（`input:checked + span`、兄弟选择器、属性选择器、:nth-child）静默 skip 到 `{`——属性照常解析、选择器被截断，无 warning——违反 ADR-054「绝不静默降级」
- 复杂选择器支持边界（兄弟/属性/伪类深化——支持哪些、拒绝哪些带诊断）
- 用户级 @media 断点样式（与响应式批次 08 协调）
- CSS 作用域/模块化（现状：class 全局命名——复杂项目样式隔离问题）

## 决议内容

1. 选择器静默跳过的修复方向裁决（诊断先行 vs 支持补齐——最小修复 = 未支持选择器 warning/error，诚实降级）
2. 复杂选择器支持边界（进语言/留生态/不支持逐项）
3. 用户级 @media 与响应式批次（08）的边界划分
4. 样式隔离/作用域是否需要（语料需求证据）
5. 本批次阶段 spec 的范围边界
